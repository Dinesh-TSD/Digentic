The app is organized by Next.js App Router route segments under `app/` (public pages, `/auth`, `/admin`, `/dashboard`, `/blog`, `/courses`, `/digital`, `/api/*`) with shared UI in `components/`, cross-cutting utilities in `lib/`, and Mongoose schemas in `models/`. Authentication is centralized in `auth.ts` using NextAuth v5 with a MongoDB adapter and a Credentials provider that reads from the `User` model; routes consume it via the `/api/auth/[...nextauth]` handler. The root `app/layout.tsx` wraps every page with the `SessionProvider` component and theme providers, while `app/admin/layout.tsx` and `app/dashboard/layout.tsx` provide role-gated shell layouts for admin and user areas. Data access flows through `lib/mongodb.ts` / `lib/mongoose.ts` which are imported by both the auth flow and API routes, ensuring all server-side code shares one database connection. Environment-driven configuration lives in `auth.config.ts`, `next.config.js`, `tailwind.config.ts`, and `.env.example`, keeping runtime secrets out of source.
