The module is a flat set of Mongoose model definitions organized by domain entity. `User.ts` declares an `IUser` interface extending `Document`, a `Schema` with field-level validation (required, trim, lowercase, match, enum), a bcrypt-backed `comparePassword` instance method, and exports a singleton `Model<IUser>` that reuses the cached mongoose model via `mongoose.models.User`. `PasswordReset.ts` similarly defines `IPasswordReset` and a schema with a MongoDB TTL index (`expires: 3600`) on `createdAt` to auto-expire tokens after one hour. `index.ts` acts as a barrel file re-exporting both models and their TypeScript interfaces for consumers. Both models explicitly pin their MongoDB collection names (`users`, `password_resets`) so they coexist with NextAuth's default collection layout.
