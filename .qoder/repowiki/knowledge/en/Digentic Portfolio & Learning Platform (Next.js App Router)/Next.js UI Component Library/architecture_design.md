Components are grouped by domain under `components/`: `home/` (landing page sections), `blog/` (post cards, sidebar, comments, tags), `admin/` (dashboard sidebar, charts, draft cards), `courses/` (video player), `user/` (user-specific cards/sidebar), plus cross-cutting pieces in `shared/` (buttons, chips, headers, progress bars) and `layout/` (Navbar, Footer, ThemeProvider, ThemeToggle). Providers live in `providers/` (`SessionProvider` wrapping next-auth's `NextAuthSessionProvider`). All components are client components marked with `'use client'`, consuming global state via React Context (`ThemeContext` in `ThemeProvider.tsx`) and next-auth session context. Styling is Tailwind CSS with the `cn` utility from `@/lib/utils`; animations come from `framer-motion`. Navigation uses `next/link` and active-route detection via `usePathname`. There is no internal routing or build manifest — this module is purely a React component tree consumed by pages elsewhere in the app.
