This leaf module provides the top-level Next.js App Router shell. `app/layout.tsx` is the root layout that injects global metadata (title, description, Open Graph/Twitter cards), loads the Inter font, and wraps all routes in a provider chain (`AuthSessionProvider` → `ThemeProvider`) plus shared chrome (`Navbar`, `Footer`). The `<html>` element defaults to dark mode via the `dark` class, and the `<main>` container uses Tailwind utility classes for spacing and background. `app/page.tsx` is the `/` route handler that composes the landing page by sequentially rendering section components from `@/components/home/*` (HeroSection, StatsBar, AboutSnapshot, FeaturedProjects, LatestBlogPosts, FeaturedCourses, DigitalAssetsPreview, Testimonials, NewsletterSignup). `app/globals.css` centralizes the design system: it imports `../styles/digentic-tokens.css`, sets up Tailwind directives, declares light/dark CSS custom properties under `:root` and `.dark`, defines base/component/utility layers, and adds blog article prose styles with dark-mode overrides. Dependency direction is one-way: this module depends on shared `@/components/*` and `@/styles/*`; nothing here is imported by feature modules beyond the root layout.
